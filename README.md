tech-support-line writes one line to a text file: the line a hopeless tech support agent gives a desperate customer. The line was picked from 36 candidates by pairwise judging against the brief — a cheerfully useless agent who closes the customer's ticket by deleting it, then brags about the closure rate. Good news up front, bad news right after, and the punchline lands on a support metric instead of the customer.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 104 characters, a single line, and ends on its strongest beat. The program builds the line from two clauses — the good news, then the bad news — and checks the result against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
